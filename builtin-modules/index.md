# Built-in Node.js Modules

Node.js comes with a set of built-in modules that provide core functionality for file system access, networking, path manipulation, and more. This section covers the most commonly used modules with practical examples.

## Modules covered

* [Path](path.md) — Work with file and directory paths in a cross-platform way
* [File System (fs)](fs.md) — Read, write, and manipulate files and directories
* [HTTP](http.md) — Create web servers and make HTTP requests
* [Events](events.md) — Work with event-driven programming
* [Streams](streams.md) — Handle large data efficiently with streaming

## Getting started

Each module page includes:
- **What it does** — Overview of the module's purpose
- **Common methods** — The most frequently used API methods
- **Practical examples** — Real-world code snippets you can use
- **When to use it** — Best practices and use cases

Start with the [Path](path.md) module for a quick introduction to working with file paths.
