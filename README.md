No videos to sit through, no slides to click next on. Just the concepts,
written down, linked together, and ready to skim, search, or hand
straight to an AI coding agent as context.

## What this is

An open knowledge base for Node.js, structured as an
[**OKF**](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md)
(Open Knowledge Format) v0.2 bundle: plain markdown files with YAML
frontmatter, cross-linked like a wiki, versioned like code. No proprietary
viewer, no schema registry, no lock-in — if you can read markdown, you can
read this.

## Why a knowledge bundle, not a tutorial

Tutorials are linear and disappear the moment you close the tab. This is
a directory: every concept is its own file, every file links to the
concepts around it, and every claim carries where it came from. Read one
page or read all of them — either way, it's just files in a folder you
can `git clone`.
