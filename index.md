# Node Knowledge Bundle

An [Open Knowledge Format](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md)
(OKF v0.2) bundle documenting the Node.js runtime: how it executes code, its
core APIs, its packaging conventions, and operational playbooks for running
it in production.

* [runtime/](runtime/) - The execution model: event loop, modules, streams, buffers, processes, errors, async patterns.

# API Reference

* [api/](api/) - Core built-in modules: fs, http, path, events, child_process, timers.

* [packaging/](packaging/) - package.json, npm scripts and lifecycle, semantic versioning.
